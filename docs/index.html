Pure Focus Architecture

Everything you need. Nothing you don't.

Zentime replaces noisy, subscription-gated blocker extensions with a clean, local-first utility designed around the human attention span.

Mode 1 • Focus Timers

Targeted Focus Timers with 3 Visual Styles

Choose between an SVG Ring, a Linear Bar, or pure Minimal digits. Set quick presets for 15, 25, 45, or 60 minutes with per-second local accuracy.

Mode 2 • Pomodoro Cycles

4-Cycle Structured Workflow

Classic 25/5m, Deep Work 50/10m, or Sprint 15/3m sessions with automatic 15-minute long breaks after 4 completed cycles.

Mode 3 • Screen Time Limits

Active-Tab Quotas & Dual Theme

Only counts active browsing time and pauses immediately when you switch tabs. Seamlessly renders in crisp Matte Light Mode.

Mode 4 • Activity Insights

7-Day Activity & Interactive Day Drilldown

High-contrast CSS/SVG bar chart showing your 7-day usage. Click on any individual day to filter top visited websites for that date. All stored locally on your machine.

Web Audio API

10-Second Harmonic Singing Bowl Chime

Synthesized pure C-Major pentatonic chords via Web Audio API. Zero external audio MP3 files, soft exponential attack, and soothing tranquil release.

Privacy Architecture

100% Offline by Design

Zentime makes zero network requests. No user accounts, no cloud database, no tracking pixels, and no data sales. Everything lives inside your browser's private local storage.

Quick Start

Get started in 30 seconds

Since Zentime is an open-source unpacked extension, you can install it in Google Chrome in 3 simple steps:

1

Download ZIP Bundle

Get the pre-built, production-ready distribution archive directly from GitHub Releases.

Download v1.0.0 (104 KB)
2

Enable Developer Mode

Open Chrome's extension manager and toggle the Developer Mode switch in the top-right corner.

chrome://extensions/
3

Load Unpacked

Extract the ZIP, click Load unpacked, and select the unzipped directory. Pin Zentime to your toolbar!
